## Quick Start Guide

### 1. Setup (5 minutes)
```bash
cd therapy-website
npm install

```
Open http://localhost:3000 in your browser

### 2. Deploy (10 minutes)
- Push to GitHub
- Import to Vercel (vercel.com)
- Get your live URL!

See **DEPLOYMENT_GUIDE.md** for detailed step-by-step instructions.

### 3. Record Video (30-40 minutes)
- Open your live site
